5. 装 WordPress：找到 Softaculous 图标，选 WordPress，填站点名和管理员账号，一分钟内装完
6. 开 SSL：在 SSL/TLS 区块用 Let's Encrypt 给域名签免费证书，自动续签
7. 装 LiteSpeed Cache 插件：WordPress 后台安装启用，默认配置就够个人站用，这一步对加载速度提升明显
8. 建邮箱：在 Email 区块创建域名下的邮箱账号

没经验的新手全程大概一两个小时。容易卡住的只有 DNS 生效那一步，一般几分钟到几小时，最长可能要等 24 小时，等的期间不用反复改解析。

入门套餐有资源上限。CloudLinux 在管每个账户的 CPU 和内存配额，站被刷一波流量、或者装了吃资源的插件，可能被临时限速。个人博客一般碰不到这个天花板，但要跑 WooCommerce 这类吃 CPU 的电商站，建议直接上促销 85 GB 或 200 GB。

IP 是共享的。共享主机给不了独立 IP，对邮件送达率要求高、或者担心同 IP 下别的站点连累信誉的话，这点要提前想清楚。

换机房要开工单。开通后想换节点，需要提交 support ticket 让客服协助迁移，没有 VPS 那种想搬就搬的灵活度。

客服响应在低价位里算快的，有测评给出的工单平均响应时间不到 10 分钟。共享主机一般还有 30 天退款保证，具体以你下单页面显示的条款为准，介意的话下单前把条款翻一遍。
